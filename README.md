# Candidate Search

## User Story:
This application will help an employer search for candidates by retriving data from GitHub API. 

## Usage:
* In the search application. The information of the candidate is displayed (name, username, location, email, html_Url, and company)
* Candidates can be saved and displayed in the potential candidate page. 
* If no candidates are selected/saved, then a message is displayed indicating no candidates have been selected.
